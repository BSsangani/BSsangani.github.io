My work covers data cleaning and analysis, SQL, dashboards, forecasting and machine learning. During my Data Analyst internship at World Standard Scientific LLP in India, I worked with 50,000+ business records using Python, SQL and Excel.

- **Languages and libraries:** Python, SQL, Pandas, NumPy, Scikit-learn
- **BI and visualisation:** Power BI, Tableau, Excel, Matplotlib, Seaborn
- **Machine learning:** regression, classification, Random Forest, XGBoost, NLP
- **Other:** SQLite, Git and GitHub
